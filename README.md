
🎓 SkillSwap LPU — Campus Peer Tutoring & Skill Exchange Marketplace

SkillSwap LPU is a zero-dependency, campus-focused peer tutoring and skill-exchange web application built with Vanilla Web technologies for Lovely Professional University (LPU), connecting 500+ students and 12+ verified peer tutors across academic blocks and residential hostels.
• 🌐 Live Website: netlify.app
• 📦 GitHub Repository: https://github.com/dushyant-lakhara/cse-326-project

📖 Overview & Key Features

SkillSwap LPU addresses student challenges regarding discoverability, high commercial tutoring costs, and unorganized study meetups by offering a structured local marketplace.
• Hyper-Local Discovery: Search mentors by specific LPU academic blocks and residential hostels, backed by live impact stats (500+ students, 40+ skills, 12+ tutors).
• Multi-Category Skills (40+ Skills): Divided into Tech (coding, DSA, web dev), Academics (engineering math, physics), Creative (UI/UX, photography, music), Languages (English, Hindi, Punjabi, foreign languages), and Life Skills (interviews, public speaking).
• Flexible Exchange Models: Choose between Skill Swap (Barter), Free Peer Sessions (volunteer mentorship), or Micro-Fee Tutoring (pocket-friendly paid sessions).
• 3-Step Workflow: Find a tutor by category/block → Book a time slot and exchange type → Meet for a 1-hour session at the LPU Central Library or block common rooms.
• Tutor Portal & Support: Students can register via the "Become a Tutor" portal or reach support at nipunr4op@gmail.com (Mon–Sat, 10:00 AM – 8:00 PM IST).

🏗 System Architecture & Tech Stack

The application relies on a lightweight client-side structure mapping user dashboards, skill explorers, and booking workflows to campus meeting venues.

Layer	Technology	Description
Markup & Semantics	HTML5	Semantic tags (<header>, <nav>, <main>, <section>, <footer>)
Styling	Vanilla CSS3	Custom CSS variables, Flexbox, CSS Grid, and responsive cards
Logic	JavaScript (ES6+)	Interactive DOM manipulation, filtering, and form validation
Hosting	Netlify	Static cloud deployment with automated SSL
Version Control	Git & GitHub	Collaborative source code management
